# 浪浪虎 — 路线规划到交互地图

一个将旅行路线规划（自驾/骑行/徒步/摩托）转化为交互式 Leaflet 地图的 Skill。

## 文件结构

```
langlang-tiger/
├── SKILL.md                       # Skill 定义（模型加载的指令集）
├── README.md                      # 本文件
├── PRD.md                         # 产品需求文档
├── examples/
│   ├── index.html                 # Case 1：贝加尔湖自驾（出境场景）
│   ├── G331/
│   │   └── G331东北边境自驾环线.html  # Case 2：G331 东北边境环线（境内场景）
│   └── map-screenshot.png         # 效果截图
└── scripts/
    ├── build.js                   # 自动化构建脚本（开发中）
    ├── validate.js                # 输出自查脚本
    └── g331.yaml                  # G331 案例 YAML 配置
```

## 示例

### Case 1：贝加尔湖自驾

从赤峰出发，经满洲里出境，自驾至贝加尔湖（奥尔洪岛），返程可选东线（经海参崴，含勘察加飞航段）或西线（经新西伯利亚、哈萨克斯坦）。

**在线预览：** https://513e84b52fcd4db29f414aa873cf3ef9.app.codebuddy.work

### Case 2：G331 东北边境自驾环线

沿 G331 国道，从赤峰出发，经满洲里→漠河→黑河→抚远→绥芬河→珲春→丹东，一路沿中蒙、中俄、中朝边境行驶。草原线/中心线双方案可选。

**在线预览：** https://bf8995ec1d4c49c199b65d964e842517.app.codebuddy.work

## 设计系统

| 路线方向 | 色值 | 色名 | 线型规则 |
|---------|------|------|---------|
| 去程首选 | `#7c3aed` | 紫色 | 实线(唯一) / 虚线(可选) |
| 去程备选 | `#2563eb` | 蓝色 | 虚线 |
| 回程首选 | `#DB536A` | 珊瑚 | 实线(唯一) / 虚线(可选) |
| 回程备选 | `#d97706` | 琥珀 | 虚线 |
| 飞航/轮渡/火车 | `#0891b2` | 青色 | 长虚线 `"6, 8"` |

| 节点类型 | 形状 | 说明 |
|---------|------|------|
| 起点/终点 | ● 大圆 | radius 8/7，circleMarker |
| 口岸 | ◆ 菱形 | 15px SVG，白边 |
| 途经城市 | ● 小圆 | radius 6，灰色 |
| 路况警告 | ▲ 三角 | 半透明黄，14px |

## 功能特性

- 🗺️ 交互式 Leaflet 地图，路线沿实际道路绘制（OSRM API）
- 🎨 线型×颜色双维度设计系统：实线=唯一路线，虚线=可选方案
- 🏷️ 8 项 UI 组件：缩放控制/底部图例/口岸筛选/飞航段/路况三角/菱形图标/起止点标记/城市标注
- 🔍 细腻缩放（zoomSnap 0.2，1/5 级步长）
- ✈️ 飞航段/轮渡/火车等交通切换节点
- 🌐 一键部署到 CloudStudio
- 📋 口岸筛选器：勾选聚焦关键节点

## 适用场景

- 出境/境内自驾路线规划
- 摩托骑行/自行车骑行路线
- 徒步穿越路线
- 多方案路线对比
